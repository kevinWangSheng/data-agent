# 提案（未定）：设置界面 + 数据库 + Slack 身份与权限

状态：**提案，未对齐**。人 2026-11-27 收尾时要求"配置不能是死的，要有设置界面，按 Slack 的权限接入"。本文件是主会话写的草稿，供下一个对齐会话逐条过；过之前不改 spec、不改票。依据：`docs/research/2026-11-27-chatbot-agent-config.md`（尤其附录 B Claude in Slack）、`docs/research/2026-11-27-config-layering-local-cloud.md`（第 4 条"环境变量播种、之后以界面为准"，Open WebUI 的旧值陷阱）。

## 1. 分层（低 → 高）

| 层 | 放什么 | 谁改 | 在哪改 |
|---|---|---|---|
| 代码默认值 | 全开、安全默认 | — | — |
| 部署文件 `config.toml` + 环境变量 | 密钥、`[server]`（host、port、mode、数据库位置）、IM 令牌、沙箱镜像与资源、可用的数据源连接、可选的模型列表 | 部署的人 | 服务器上的文件、容器环境变量 |
| 设置（数据库）：工作区 → 频道 → 个人 | 用哪个模型、频道用哪些数据源、Skill 与说明、MCP 连接（从部署层登记的里面选）、联网、effort、上限（不超过锁定值） | 见第 2 节 | 网页 Settings；Slack 里 `@bot !configure` |
| 锁定 `[policy]`（部署文件） | 允许的模型、联网上限、`dbt_target`、花费上限的天花板 | 部署的人 | 文件；界面上显示为灰色不可改 |

- 首次启动时用 `config.toml` 里的设置类键给数据库播种；之后以数据库为准（nao、Open WebUI 的做法）。为避开"改了文件不生效"的坑，`config show` 和设置页都标出每个值来自哪一层。
- 每次运行开始时读一次生效设置（文件 + 数据库 + 锁定），改完下一次运行就生效，不用重启。
- 个人层只用于私聊和本人的偏好（照 Claude in Slack：频道里用频道的设置，一对一私聊才用个人的）。
- 评测不用数据库：评测入口照旧只读 `evals/profiles/` 的文件（ADR-0011 第 3 条不变），复现性不受影响。

## 2. 身份与权限（接 Slack）

- 网页登录：cloud 模式用"Sign in with Slack"（OpenID Connect），拿 Slack 用户 id 和工作区 id，只接受配置的那个工作区。local 模式（只监听本机）不登录，本机用户就是管理员。工单 156 的"输一次令牌换 Cookie"被这个替代；bearer 令牌只留给脚本调用 API。
- 角色从 Slack 取（`users.info` 的 `is_admin`/`is_owner`）：
  - 工作区层：工作区 Owner/Admin。
  - 频道层：频道成员可看；谁能改待定（推荐：频道成员都能改，部署的人可在 `[policy]` 里收紧为只有管理员）。
  - 个人层：本人。
- Slack 里 `@bot !configure`：回一个只有本人可见的链接，打开本频道的设置页。
- 每次设置改动记一条审计：谁、什么时候、哪一层、改了什么。

## 3. 会话

- 一个 Slack 线程是一次会话（现状不变）。bot 的回复带"在网页打开"链接，进入这次运行的页面；能不能看按 Slack 频道成员身份判断（`conversations.members`），私聊只有本人。
- 网页里的对话存进数据库，带所有者。

## 4. 存储

- sqlite（单台服务器够用），有迁移；运行记录照旧是文件。设置表的字段和 `config.toml` 的分节是同一套有类型的 schema，按作用域（工作区、频道 id、用户 id）各存一份覆盖。
- 一期不在界面里新增带密码的数据源连接（那需要加密存储，照 SignalPilot/Dify 用环境变量里的密钥加密）；数据源连接仍由部署层登记，界面只选用。

## 6. 要对齐的点（每条附推荐）

1. 频道层谁能改：推荐频道成员都能改，`[policy]` 可收紧到只有管理员。
2. 一期是否允许在界面新增数据源连接：推荐不允许，只选用部署层登记的。
3. 单条消息的覆盖（如 `profile=`、`model=`）：推荐放二期。
4. 多个 Slack 工作区：推荐一期只支持一个。
5. Telegram、Discord 没有工作区管理员的概念：推荐它们只用部署层 + 允许名单，不进设置页的权限模型（未调研，需确认）。
6. 和 ADR-0011 的关系：写 ADR-0012 取代 ADR-0011 第 5 条，改 `docs/plan.md` §1。
